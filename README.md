# 솔안과 근무표 — 설치 안내

팀장들이 각자 팀 근무표를 짜고, 원장님(관리자)이 전체를 관리하는 웹 프로그램이에요.

- **프로그램(화면)** 은 GitHub Pages에 올려서 링크 하나로 누구나 열 수 있어요.
- **데이터(근무표·직원·설정)** 는 원장님 구글 드라이브에 파일 하나로 저장돼요.
- 둘을 이어 주는 작은 서버 프로그램이 구글 Apps Script(`Code.gs`)예요. 무료예요.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 근무표 프로그램 |
| `config.js` | 서버 주소 한 줄 (아래 2단계에서 넣어요) |
| `apps-script/Code.gs` | 구글 Apps Script 서버 코드 (보관용 사본, 실제로는 1단계처럼 Apps Script에 붙여 넣어요) |

---

## 1단계. 구글 서버 만들기 (약 10분)

1. 원장님 구글 계정으로 <https://script.google.com> 에 들어가 **새 프로젝트**를 만들어요.
2. 왼쪽 위 프로젝트 이름을 `솔안과 근무표 서버`로 바꿔요.
3. 편집기에 있는 `Code.gs`의 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 **저장**해요. (GitHub에서 파일을 열고 오른쪽 위 복사 버튼을 누르면 편해요.)
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴(유형 선택)에서 **웹 앱**을 골라요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르면 권한 승인 창이 떠요. 계정을 고르고 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누르세요.
   직접 만든 스크립트라서 뜨는 경고예요. 이 스크립트는 자기가 만든 데이터 파일 하나만 읽고 써요.
6. 화면에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 두세요.

> 나중에 `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 이렇게 하면 주소는 그대로예요.

## 2단계. GitHub에 올리기 (약 5분)

1. <https://github.com/new> 에서 저장소 이름을 `sol-roster`로 하고 **Public**으로 만들어요.
2. **Add file → Upload files**로 `index.html`과 `config.js`를 올리고 **Commit changes**를 눌러요.
3. 저장소에서 `config.js`를 열고 연필(편집)을 눌러, 따옴표 안에 1단계의 웹 앱 URL을 붙여 넣고 저장해요.
   ```js
   window.SOL_ROSTER_API = "https://script.google.com/macros/s/AKfy…/exec";
   ```
4. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요.
   1~2분 뒤 `https://(GitHub 아이디).github.io/sol-roster/` 주소가 생겨요.

## 3단계. 처음 접속하기

1. **원장님이 가장 먼저** 주소를 열고 **관리자 PIN**을 만드세요. 가장 먼저 만든 사람이 관리자가 돼요.
2. 다음 순서로 설정하세요. 고친 내용은 **자동으로 저장**돼요.
   1. **진료 시간:** 요일별 진료 시간과 날짜별 변경을 정해요.
   2. **근무 형태:** 외근·교육 같은 근무 형태를 추가해요.
   3. **팀·직원:** 팀 이름, 팀장 이름, 직원, 요일별 최소 인원을 넣어요. 팀 표의 **▲▼**로 팀 순서를 바꾸면 근무표의 팀 순서와 달력의 ‘○○오프’ 줄 순서도 같이 바뀌어요.
3. **팀·직원**의 **팀장**에서 팀장을 사람마다 이름·팀·PIN으로 등록해요. 한 팀에 여러 명도 돼요. 팀을 새로 만들었다면 자동 저장이 끝난 뒤(몇 초) 등록하세요.
4. 팀장에게 주소와 각자의 PIN을 알려 주세요. 직원들에게도 보여 주려면 **열람 PIN**을 정해서 알려 주세요.

## 자동 저장

구글 시트처럼 **고친 내용이 바로 저장**돼요. 따로 누를 저장 버튼이 없어요.

- 위쪽 오른쪽에 저장 상태가 보여요: `곧 저장돼요` → `저장 중…` → `자동 저장됨 · 10/21 11:30`.
- 마지막으로 고치고 1.5초쯤 지나면 저장돼요. 다른 탭이나 앱으로 넘어가면 바로 저장해요.
- 인터넷이 끊기면 `저장 안 됨`과 **다시 저장** 버튼이 나와요. 연결되면 자동으로 다시 저장해요. 이때 창을 닫으려 하면 브라우저가 한 번 물어봐요.
- 근무표 화면을 한동안(1분 이상) 다른 탭에 두었다가 돌아오면, 다른 사람이 고친 최신 내용을 자동으로 불러와요. 바로 확인하려면 **↻**를 누르세요.
- 실수했다면 **되돌리기**로 고치기 전 상태로 돌릴 수 있어요(아래 ‘저장 전으로 되돌리기’).

## 근무표 보기

- **달 바꾸기:** 근무표 위쪽 **‹ 10월 · 11월 · 12월 ›** 버튼으로 이전 달·다음 달로 넘어가요.
- **달력(기본):** 지금 쓰는 구글 시트 근무표처럼 노란 제목 줄과 주마다 날짜 줄 아래에 **야간 · 팀별 오프(예: 외래오프) · 연차 · 포상 · 인원**이 나와요. 연차 옆 `Y숫자`는 올해 그날까지 쓴 연차 수예요. 줄 이름은 관리자가 **근무 형태 → 달력 줄 이름**에서 바꿀 수 있어요.
- **시트처럼 칸을 눌러 이름 넣기:** 달력의 칸(예: 6일 외래오프)을 누르면 왼쪽에 이름이 나와요. 이름을 누르면 그 칸에 들어가고, 칸 안의 이름을 다시 누르면 빠져요. 메모(변경불가·신행 등)는 이름 옆 칸에 적으면 달력에 `이름(메모)`로 보여요.
  - **연차 칸:** 위에서 연차·오전 반차·오후 반차나 **반반차**를 고른 뒤 이름을 눌러요.
  - **반반차(0.25일):** 오전이나 오후 진료 시간의 앞쪽 또는 뒤쪽 절반(보통 2시간)만 쉬어요. **오전 앞**(9~11시 쉬고 11시 출근), **오전 뒤**(11~13시 쉬고 점심 뒤 복귀), **오후 앞**(14~16시 쉬고 16시 복귀), **오후 뒤**(16~18시 쉬고 16시 퇴근) 네 가지예요. 시간은 그날 진료 시간에 맞춰 바뀌고, 토요일처럼 오후 진료가 없는 날은 오전 반반차만 고를 수 있어요. 달력에는 `이름 반반 9~11시 Y15.25`처럼, 표에는 `반반`과 `전앞·전뒤·후앞·후뒤`로 보여요. 연차에서 0.25일 빠지고, 근태 탭에서도 그 시간 기준으로 지각·조퇴를 따져요.
  - **포상 칸:** 조퇴·늦은 출근 시간(5분 단위), 외근·교육 같은 일정, 사유 메모를 넣어요. 달력에 `김미진 10:25 퇴근(10/12 연장)`처럼 보여요.
  - 날짜별로 야간이 없는 날은 야간 줄에 빨간 **야간없음**이 나와요. 휴직 시작일은 날짜 줄에 자동으로 적혀요.
- **날짜 숫자를 누르면** 달력 **왼쪽**에 그날 직원 목록이 열려요(좁은 화면에서는 아래에서 올라와요). 달력은 그대로 보이니 한 달을 보면서 고칠 수 있어요.
  - 이름 아래 **근·전반·후반·반반·연·휴·외·교·경** 버튼을 누르면 바로 바뀌고, **같은 버튼을 한 번 더 누르면 지워져요.** ‘반반’을 누르면 오전 앞·오전 뒤·오후 앞·오후 뒤가 나와요.
  - 시간 조정(조퇴·늦은 출근), 희망휴무, **날짜 메모**(예: 미진 야간불가), **사람 메모**(예: 변경불가)도 여기서 넣어요. 사람 메모는 달력에 `이름(메모)`로 보여요.
  - 사람마다 `이번 주 5/5일`처럼 그 주에 잡힌 근무일이 보여요. 주 근무일과 다르면 노란색이에요.
  - ‹ › 로 전날·다음 날로 넘어가요. 날짜를 고르기 전에는 이 자리에 **확인할 것**(인원 부족, 주 근무일 안 맞음, 휴무 겹침)이 나와요.
- **휴무·연차를 넣지 않은 날은 근무로 계산해요.** 그 사람이 나오는 요일에만 해당하고, 표에서는 흐린 ‘근’으로 보여요. 휴무·연차만 넣고 **자동 생성**을 누르면 나머지를 알아서 짜 줘요.
- **표:** 한 달 전체를 드래그로 한꺼번에 칠할 때 써요. 칸 색: 야간 남색, 연차·반차 노랑, **휴무 주황**, 외근 파랑, 대체휴무 청록, OT 사용 보라. 위쪽 **달력 / 표** 버튼으로 바꿔요. 같은 형태로 칠한 칸을 다시 누르면 지워지고, **지우기**로도 지울 수 있어요. 고른 근무 형태 버튼(예: `근 근무`)을 한 번 더 누르면 선택이 풀려요.
- **같은 날 함께 쉬면 안 되는 직원:** **팀·직원(우리 팀 직원)** 아래쪽에서 팀장이 자기 팀 직원끼리 묶어요. 다른 팀 직원끼리는 관리자가 **생성 조건**에서 묶어요. 묶인 사람이 이미 쉬는 날 다른 사람을 오프·연차에 넣으려 하면 이름 옆에 `같이 못 쉼`이 보이고, 한 번 더 눌러야 들어가요.
- **정기 휴무 요일:** 팀·직원의 ‘근무 가능 요일’에서 꺼 둔 요일은 달력의 오프 칸에 자동으로 나와요. 그 사람을 오프 칸에서 누르면 그날만 근무로 바뀌어요.
- **요일별 최소 인원:** 팀·직원 위쪽 표에서 월~일 요일마다 **주간**(오전·오후 각각)과 **야간** 최소 인원을 정해요. 휴진 요일은 비어 있고, 야간 칸은 야간 진료가 있는 요일에만 있어요. 자동 생성과 ‘인원 부족’ 표시가 이 숫자를 따라요.
- **꼭 근무해야 하는 요일:** 직원 줄의 ‘근무 가능 요일’ 아래 **꼭** 줄에서 요일을 누르면, 자동 생성이 그 요일엔 휴무를 넣지 않아요. 근무 가능한 요일만 고를 수 있고, 직접 넣은 휴무·연차는 그대로 둬요.
- **야간 필수:** 야간 ‘가능’ 아래 **필수**를 체크한 직원들 가운데 **최소 1명은 야간 진료가 있는 날마다 야간에** 들어가도록 자동 생성이 짜요. 손으로 고쳐서 필수 직원이 아무도 야간에 없으면 위쪽에 ‘야간 필수 직원 없음’이 떠요.
- **기간별 설정:** 직원 줄의 ‘평소 근무시간’ 아래 **기간별 설정**을 누르면, 정한 기간에만 **평소 근무시간**(일찍 퇴근·늦게 출근)이나 **야간**(안 함·가능·가능+필수)을 바꿀 수 있어요. 예: 11/9~3/31 2시간 일찍 퇴근, 신규 직원은 12/1부터 야간 가능(끝 날짜를 비우면 계속). 기간 밖에서는 그 줄의 평소 설정을 따라요. 근무시간 계산·자동 생성·야간 필수·근태의 지각/조퇴 판단이 모두 날짜별로 이 설정을 따르고, 근무표 표의 이름 아래에 `11/9~11/20 2시간 일찍 퇴근`처럼 보여요.
- **직원 순서·휴직:** **팀·직원(우리 팀 직원)**에서 ▲▼로 순서를 바꾸고, 육아휴직·출산휴가처럼 오래 쉬는 직원은 **휴직**에서 기간을 정해요. 휴직 기간은 근무표에 ‘휴직’으로 보이고 자동 생성·인원·근무일 목표에서 빠져요.
- **앞서 쓴 연차:** 프로그램을 쓰기 전에 올해 이미 쓴 연차가 있으면 **팀·직원**에서 넣어 주세요. Y숫자가 거기서 이어져요.
- **인쇄:** **내보내기 → 인쇄용 달력**은 A4 가로로 지금 쓰는 양식처럼 뽑혀요.

## 연차·OT 관리

- **오전반차 + 야간:** 오전에 쉬고 오후·야간에 나오는 날은 연차 칸에서 ‘오전 반차’로 넣고 야간 칸에도 넣으면 돼요(반야). 둘 중 하나만 빼면 나머지는 남아요.
- **반반차 + 야간:** 반반차를 쓰고 야간도 하는 날은 연차 칸에서 반반차로 넣고 야간 칸에도 넣으면 돼요(순서는 상관없어요). 표에는 `반반야`로 보이고, 야간 줄에는 `이름 반반 9~11시 쉼`처럼 쉬는 시간이 함께 나와요. 오후 뒤 반반차+야간은 16~18시만 쉬고 야간 진료에 다시 나오는 거예요. 날짜 화면에서는 ‘야’와 ‘반반’ 버튼이 함께 눌려 있고, 둘 중 하나만 다시 누르면 그것만 빠져요.
- **연차 (입사일 기준·1월 1일 기준):** 팀·직원의 ‘연차 · OT’ 칸에 입사일, 총 연차, 앞서 쓴 연차, 이전에 쌓인 OT(이월)를 넣어요.
  - **입사일을 넣은 직원**은 연차가 **매년 입사한 날에 새로 생겨요**(예: 입사일 5/10 → 2026.5.10~2027.5.9가 한 기간). 그날부터 사용 일수와 달력의 연차 번호(Y1, Y2…)를 처음부터 다시 세서, 지난 기간에 쓴 연차가 새 연차에서 빠지지 않아요.
  - **입사일을 비워 두면** 지금처럼 1월 1일~12월 31일 기준이에요.
  - 입사일이 있으면 **총 연차를 비워도 근로기준법 일수로 자동** 계산해요: 1년 미만은 한 달 개근마다 1일(최대 11일), 1년이 되면 15일, 3년차부터 2년마다 1일 더(최대 25일). 표에는 `15 법정`처럼 보여요. 병원 기준이 다르면(개근 못 한 달이 있는 신입 등) 직접 넣으세요.
  - ‘총 연차’·‘앞서 씀’ 칸은 위에서 보고 있는 **달의 말일이 속한 기간** 값이에요. 지난 기간 값을 고치려면 그 기간의 달로 넘겨서 고치세요. 근무표 아래 ‘연차·OT 현황’도 그 달 말일이 속한 기간을 보여 줘요.
  - 입사일을 처음 넣으면 기간이 바뀌니, 그 직원의 총 연차·앞서 씀을 새 기간에 맞게 한 번 확인하세요.
- **OT 적립:** 야간 근무는 자동으로 2시간 → OT 3시간이 쌓이고(그 달 안에 쓰고, 남으면 월말에 수당으로 정산), 수납 OT는 관리자는 **근태** 탭, 팀장은 **근무표** 탭 아래 **수납 OT**에서 기록해요. 그 밖의 OT는 근무표 맨 아래 **연차·OT 현황 → OT 기록하기**에서 기록해요.
- **야간 대체 · OT 사용:** 포상 칸이나 날짜 화면의 시간 칸에서 **일찍 퇴근 — 야간·OT 고르기** 또는 **늦게 출근 — 야간·OT 고르기**를 고르면 작은 상자가 열려요.
  - **야간 대체**: 지난달·이번 달 근무표의 야간 날짜가 버튼으로 나와요(야간 1번 = 보통 3시간). 누르면 그 야간을 수당 대신 쉬는 시간으로 써요. 이미 다른 날에 쓴 야간은 `11/26에 씀`으로 막혀요.
  - **OT 사용**: 쌓인 OT에서 5분 단위로 골라요. 오래된 OT부터 빠져요.
  - 둘을 **더한 만큼** 일찍 퇴근하거나 늦게 출근해요. 예: 11/2 야간(3시간) + OT 20분 → `송진형 14:40 퇴근 (11/2 야간, 11/1 OT 20분)`처럼 달력에 출처가 자동으로 붙어요.
  - 야간 대체로 쓴 야간은 **다른 달에 썼어도** 근태 정산의 야간 수당에서 빠지고, 정산표의 **야간 대체** 열에 보여요.
  - **미리 쓰기:** 다음 달 야간으로 채울 생각으로 이번 달에 먼저 쉬어도 돼요.
    - 다음 달 근무표에 그 야간이 있으면, 야간 대체에서 다음 달 날짜(`12/7 야간 · 미리`)를 바로 고르세요.
    - 다음 달 근무표를 아직 안 짰다면 **OT 사용**으로 필요한 만큼 고르세요. `미리 쓴 OT 3시간`으로 남았다가, 다음에 하는 야간(또는 OT)으로 자동으로 채워져요. 달력에는 `(미리 쓴 OT 3시간 → 12/7 야간으로 채움)`처럼 보이고, 그 야간은 야간 수당에서 빠져요.
- **대체오프 (평일 OT 9시간, 토요일 6시간):** 야간(3시간)을 모아 하루 쉬는 날이에요. 평일은 3번(9시간), 토요일은 2번(6시간)이에요.
  - 넣는 곳: 달력의 **오프 칸 → 위에서 ‘대체오프’ 고르고 이름 누르기**, 또는 포상 칸·날짜 화면의 시간 칸에서 **대체오프 (OT 9시간 사용)**.
  - 평일은 **9시간**, 토요일은 **6시간**이에요. 야간 진료가 있는 날(월·금)도 18시에 퇴근하는 하루로 봐서 9시간만 빠져요.
  - 넣으면 **모은 야간** 버튼이 나와요. 지난달~다음 달 야간 중 쓴 것을 고르면(평일 최대 3번·9시간, 토요일 최대 2번·6시간) 그 야간은 **야간 수당에서 빠지고**, 모자란 만큼만 쌓인 OT에서 빠져요. 안 고르면 쌓인 OT에서 9시간(토요일 6시간)이 빠져요(모자라면 ‘미리 쓴 OT’로 남았다가 다음 야간·OT로 채워져요).
  - 달력 오프 줄에는 `김미진 대체오프 (11/2·11/6·11/9 야간)`처럼 보여요. 평일에 진료 시간을 반일로 바꾼 날에는 넣을 수 없어요(그날은 **OT 하루 전체**를 쓰세요).
  - 맨 아래 **OT 하루 전체**를 고르면 그날 근무시간만큼 OT에서 빠져요. OT·야간과 상관없는 조퇴·늦은 출근은 ‘시간 조정’ 묶음에서 골라요.
- **연차·OT 현황** 표에서 직원마다 올해 연차·사용·남음, 이번 달 OT 적립·사용, 남은 OT를 봐요. 팀장·관리자에게만 보여요.

## 근무 배치 (6번 탭)

누가 어느 자리(1번 진료실, 데스크, 수술실 …)에서 일하는지 날짜별로 정해요.

1. 아래쪽 **배치 자리**에서 팀의 자리를 만들어요. 자주 쓰는 자리는 버튼 한 번, 나머지는 직접 입력해요. **하루 필요 인원**을 정하면 모자랄 때 빨간색으로 보여요.
2. **직원별 기본 자리**를 정해 두면 근무하는 날마다 그 자리에 자동으로 들어가요.
3. 배치표의 **칸을 누르고 이름을 고르면** 그날 그 자리에 들어가요. 다시 누르면 빠져요.
4. **빈 자리 채우기**는 아직 자리가 없는 사람을 모자란 자리에 돌아가며 넣어요.
5. **한 주 / 하루**로 보기를 바꾸고, **인쇄용 배치표**로 뽑아 붙일 수 있어요.

근무표에서 휴무·연차·외근인 사람은 ‘쉼’ 줄에 나오고 자리에 들어가지 않아요. 팀장은 자기 팀만 고치고, 직원(열람)은 보기만 해요.

## 근태 (7번 탭, 관리자만)

지문 기록(출퇴근) 엑셀을 근무표와 맞춰 보고, 월말에 OT·공휴일 근무를 정산해요. **관리자만** 볼 수 있어요. 팀장·직원 화면에는 근태 탭이 없고, 지문 기록도 서버에서 관리자에게만 보내요.

1. **지문 기록 올리기**(관리자): 지문 프로그램에서 받은 엑셀(.xlsx)이나 CSV를 그대로 올려요. `근무일자·이름·출근시간·퇴근시간` 열을 읽어요. 근무표에 없는 이름은 다른 직원으로 연결하거나, 지문만으로 정산하거나, 제외할 수 있어요. 올리면 자동 저장돼요.
2. **수납 OT**(관리자는 여기, 팀장은 **근무표** 탭 아래): 마지막 환자 수납이 정규 종료보다 늦은 날, 수납 시간과 남았던 당번을 기록해요. 넘은 시간을 5분 단위로 올리고 +20분이 OT 휴무예요 (18:06 → 30분, 18:01 → 25분).
3. **날짜별 비교**: 근무표와 지문을 날짜마다 맞춰 보고 지각·일찍 퇴근·지문 없음·근무표와 다른 야간 근무를 ‘확인할 점’으로 보여 줘요. **고치기**로 빠진 지문이나 인정 시간을 바꿀 수 있고, 일찍 퇴근한 날은 **OT 사용으로** 버튼으로 근무표에 OT 조퇴를 바로 넣을 수 있어요.
4. **정산표**: 야간 근무 → OT(2시간 = 3시간), 수납 OT, OT 사용, 공휴일 근무, 대체휴무를 상계해서 **남은 야간·남은 공휴일 근무시간(1.5배 지급)**을 보여 줘요. 관리자는 두 칸을 직접 고칠 수 있고(자동 값으로 되돌리기 가능), **정산표 받기**(CSV)·**인쇄**로 급여 담당에게 넘기면 돼요.

규칙: OT를 쓰면 수납·기타 OT부터(오래된 것부터) 빠지고, 모자라면 그 달 야간 OT에서 빠져요. 그 달 야간 OT가 남으면 수당으로 정산하고, 수납·기타 OT는 다음 달로 넘어가요. 공휴일 근무는 근무표의 **대체휴무**(오프 칸에서 ‘대체휴무’ 고르기)와 그 달 안에서 하나씩 상계돼요. 정규 종료 시간(평일 18:00 / 야간 있는 날 20:00 / 토요일 15:00)과 반올림 방식·배율은 근태 탭 맨 아래 **계산 규칙**에서 관리자가 바꿀 수 있어요.

지문 기록은 근무표 데이터 파일에 달마다 저장돼요. 팀장 화면의 ‘연차·OT 현황’은 지문 기록 없이 **근무표 기준**으로 계산해요. 그래서 근무표엔 주간인데 지문상 야간까지 남은 날처럼 지문으로만 알 수 있는 OT는 관리자 근태 화면에만 반영돼요.

## 취업규칙 (8번, `rules.html`)

우리 병원에서 시행 중인 규칙과 복지(근무 시간, OT 사용, 연차 신청, 경조사, 급여일, 복지 등)를 적어 두고, 직원들이 검색해서 찾아봐요.

근무표와 **따로 떨어진 페이지**예요. 근무표 메뉴의 **취업규칙 ↗**을 누르면 새 탭으로 열리고, 주소(`…/sol-roster/rules.html`)로 바로 열어도 돼요. 근무표를 열 때는 취업규칙을 불러오지 않아서 근무표 속도에 영향이 없어요. 내용은 근무표와 같은 구글 드라이브 데이터 파일에 저장돼요. **관리자만** 쓰고 고칠 수 있고, 팀장과 직원은 보기만 해요. 근무표에 로그인한 상태로 열면 그대로 이어지고, 아니면 페이지 위쪽 **관리자 로그인**으로 PIN을 넣으면 돼요.

1. 처음에는 **자주 쓰는 항목 틀 넣기**를 누르면 12개 항목이 들어가요. 노란 **[ ]** 칸만 우리 병원에 맞게 고치고, 필요 없는 항목은 지우면 돼요.
2. **+ 새 항목**으로 분류·제목·내용을 적어요. **누가 볼 수 있나요**에서 ‘관리자·팀장만’을 고르면 직원 화면에는 보이지 않아요(서버가 아예 보내지 않아요).
3. 저장하면 **바로** 모든 사람에게 보여요. 두 사람이 같은 항목을 동시에 고치면 나중에 저장한 사람에게 안내가 떠요.
4. **인쇄용 파일**로 뽑아 게시판에 붙일 수 있어요. 근로기준법상 취업규칙은 직원들이 언제든 볼 수 있게 해 둬야 해요.

직원 개인의 급여·연락처 같은 개인정보는 적지 마세요.

> 이 탭은 직원들이 찾아보기 쉽게 정리하는 곳이에요. 상시 10명 이상인 병원은 취업규칙을 고용노동부에 **신고**해야 하고, 직원에게 불리하게 바꿀 때는 직원 과반수의 **동의**가 필요해요. 신고·동의는 따로 진행하세요.

## 근로기준법 (9번, `law.html`)

서버를 쓰지 않는 가벼운 페이지라 바로 열려요. 연차·반차·공휴일·출산휴가·육아휴직·OT·퇴직금·최저임금 같은 자주 묻는 내용을 쉬운 말로 정리했어요(2026년 10월 기준). 검색창이나 **자주 찾는 말** 버튼으로 찾고, **자세히 보기**를 누르면 근거 조문(국가법령정보센터 링크)이 나와요. **내 연차 계산기**에 입사일을 넣으면 법정 연차를 알려 줘요. 우리 병원 취업규칙에 같은 내용이 있으면 바로 가는 버튼이 생겨요.

이 안내는 이해를 돕기 위한 요약이라 법적 효력은 없어요. 법과 금액이 바뀌면 프로그램도 고쳐야 해요. 정확한 답은 고용노동부 상담센터(☎ 1350)나 노무사에게 확인하세요.

## 저장 전으로 되돌리기

고친 뒤에 실수를 알았다면 위쪽 **되돌리기** 버튼을 누르세요. 자동 저장은 같은 사람이 **10분 안에 이어서 고친 것을 한 번으로 묶어서** 남겨요. 그래서 되돌리면 그 사람이 고치기 시작하기 전 상태로 돌아가요.

1. 최근 저장 목록이 나와요. 예: `외래팀 2026년 11월 근무표 · 10/21 14:02 ~ 14:32 · 김팀장 고침 (자동 저장 12번)`
2. 되돌릴 항목의 **이 저장 전으로 되돌리기**를 누르고, 한 번 더 확인하면 **그 저장 바로 전 상태**로 돌아가요.
3. 되돌리기도 기록에 남아요. 잘못 되돌렸다면 목록 맨 위 항목을 다시 되돌리면 돼요.

- **누가 무엇을:** 팀장은 **자기 팀 근무표·직원 명단**만, 관리자는 모든 팀과 진료 시간·근무 형태·팀 설정·근태까지 되돌릴 수 있어요.
- **몇 번까지:** 근무표는 팀·달마다, 직원 명단은 팀마다 최근 8번(근태는 달마다 3번)까지 남아요. 기록은 이 기능을 넣은 뒤부터 쌓여요.
- **그 뒤에 또 저장했다면:** 목록에 `이 뒤에 N번 더 저장됐어요`가 보여요. 되돌리면 그 뒤에 저장한 내용도 함께 사라지니 확인하고 누르세요.
- 아직 저장 중인 변경이 있으면 먼저 저장한 뒤에 되돌려요.
- 팀을 지웠다가 되돌리면 팀·직원·근무표는 돌아오지만, **팀장 PIN은 돌아오지 않아요.** 관리자가 팀장을 다시 등록해 주세요.

## 데이터와 보안

- **데이터 파일:** 원장님 구글 드라이브에 있는 `솔안과_근무표_데이터.json` 파일 하나예요. 지우거나 이름을 바꾸지 마세요. 가끔 이 파일을 복사해 두거나, 프로그램의 **전체 백업 파일**로 받아 두면 좋아요.
- **PIN 보관:** PIN은 그대로 저장하지 않고 암호화(해시)해서 Apps Script 설정에만 보관해요. 데이터 파일에는 PIN이 없어요.
- **저장 기록:** 근무표마다 마지막으로 저장한 사람과 시간이 팀 줄에 표시돼요. 되돌리기용 이전 버전은 같은 드라이브의 `솔안과_근무표_저장기록.json`에 따로 보관돼요(지우면 되돌리기 목록만 비고 근무표는 그대로예요).
- **팀장이 그만두면:** 관리자가 **팀·직원 → 팀장**에서 그 사람만 삭제하면 돼요. 같은 팀 다른 팀장의 PIN은 그대로예요.
- **잠금:** PIN을 10번 틀리면 10분 동안 로그인이 막혀요.
- **공개 범위:** GitHub Pages는 공개 저장소라서 프로그램 코드와 `config.js`의 서버 주소는 누구나 볼 수 있어요. 직원 이름과 근무표를 아무나 보지 못하게 하려면 **열람 PIN을 꼭 정하세요**. 근무표에는 환자 정보를 넣지 마세요.
- **여러 팀장이 동시에 고칠 때:** 근무표는 **팀·달 단위**로 저장돼요.
  - 외래팀장과 검안팀장처럼 **다른 팀**이 같은 시간에 저장해도 서로 덮어쓰지 않아요.
  - **같은 팀·같은 달 근무표**를 두 사람(예: 관리자와 그 팀 팀장)이 동시에 고쳐도, 칸 단위로 **두 사람의 변경을 합쳐서** 저장해요. 같은 칸을 둘 다 고쳤다면 나중에 고친 사람 것이 남아요. 합쳐지면 "두 사람의 변경을 합쳐 저장했어요" 안내가 떠요.
  - **직원 명단·진료 시간 설정**을 두 사람이 동시에 고치면 합칠 수 없어서, 나중 사람에게 "자동 저장을 멈췄어요" 안내가 떠요. **최신 내용 불러오기**를 누른 뒤 다시 고치면 돼요.
  - 다른 사람이 저장한 내용은 위쪽 **↻**를 누르면 보여요.
- **관리자 PIN을 잊었을 때:** Apps Script 편집기 위쪽에서 함수 `resetAdminPin`을 고르고 **실행**하세요. 다음 접속 때 관리자 PIN을 새로 만들 수 있어요.

## 혼자 쓰기 모드

`config.js`의 주소를 비워 두면 서버 없이 이 브라우저에만 저장되는 혼자 쓰기 모드로 열려요. 위쪽 **미리보기**에서 팀장·직원 화면을 확인해 볼 수 있어요.
