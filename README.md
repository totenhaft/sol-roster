# 솔안과 근무표 — 설치 안내

팀장들이 각자 팀 근무표를 짜고, 원장님(관리자)이 전체를 관리하는 웹 프로그램이에요.

- **프로그램(화면)** 은 GitHub Pages에 올려서 링크 하나로 누구나 열 수 있어요.
- **데이터(근무표·직원·설정)** 는 원장님 구글 드라이브에 파일 하나로 저장돼요.
- 둘을 이어 주는 작은 서버 프로그램이 구글 Apps Script(`Code.gs`)예요. 무료예요.

| 파일 | 하는 일 |
|---|---|
| `index.html` | 근무표 프로그램 |
| `config.js` | 서버 주소 한 줄 (아래 2단계에서 넣어요) |
| `apps-script/Code.gs` | 구글 Apps Script 서버 코드 (보관용 사본, 실제로는 1단계처럼 Apps Script에 붙여 넣어요) |

---

## 1단계. 구글 서버 만들기 (약 10분)

1. 원장님 구글 계정으로 <https://script.google.com> 에 들어가 **새 프로젝트**를 만들어요.
2. 왼쪽 위 프로젝트 이름을 `솔안과 근무표 서버`로 바꿔요.
3. 편집기에 있는 `Code.gs`의 내용을 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 통째로 붙여 넣은 뒤 **저장**해요. (GitHub에서 파일을 열고 오른쪽 위 복사 버튼을 누르면 편해요.)
4. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴(유형 선택)에서 **웹 앱**을 골라요.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르면 권한 승인 창이 떠요. 계정을 고르고 **고급 → (프로젝트 이름)(으)로 이동 → 허용**을 누르세요.
   직접 만든 스크립트라서 뜨는 경고예요. 이 스크립트는 자기가 만든 데이터 파일 하나만 읽고 써요.
6. 화면에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 두세요.

> 나중에 `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 눌러야 반영돼요. 이렇게 하면 주소는 그대로예요.

## 2단계. GitHub에 올리기 (약 5분)

1. <https://github.com/new> 에서 저장소 이름을 `sol-roster`로 하고 **Public**으로 만들어요.
2. **Add file → Upload files**로 `index.html`과 `config.js`를 올리고 **Commit changes**를 눌러요.
3. 저장소에서 `config.js`를 열고 연필(편집)을 눌러, 따옴표 안에 1단계의 웹 앱 URL을 붙여 넣고 저장해요.
   ```js
   window.SOL_ROSTER_API = "https://script.google.com/macros/s/AKfy…/exec";
   ```
4. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요.
   1~2분 뒤 `https://(GitHub 아이디).github.io/sol-roster/` 주소가 생겨요.

## 3단계. 처음 접속하기

1. **원장님이 가장 먼저** 주소를 열고 **관리자 PIN**을 만드세요. 가장 먼저 만든 사람이 관리자가 돼요.
2. 다음 순서로 설정하고 오른쪽 위 **저장**을 누르세요.
   1. **진료 시간:** 요일별 진료 시간과 날짜별 변경을 정해요.
   2. **근무 형태:** 외근·교육 같은 근무 형태를 추가해요.
   3. **팀·직원:** 팀 이름, 팀장 이름, 직원, 필요 인원을 넣어요.
3. **팀·직원**에서 팀마다 **팀장 PIN**을 정해요. 팀을 새로 만들었다면 먼저 저장한 다음에 PIN을 정하세요.
4. 팀장에게 주소와 팀 PIN을 알려 주세요. 직원들에게도 보여 주려면 **열람 PIN**을 정해서 알려 주세요.

## 데이터와 보안

- **데이터 파일:** 원장님 구글 드라이브에 있는 `솔안과_근무표_데이터.json` 파일 하나예요. 지우거나 이름을 바꾸지 마세요. 가끔 이 파일을 복사해 두거나, 프로그램의 **전체 백업 파일**로 받아 두면 좋아요.
- **PIN 보관:** PIN은 그대로 저장하지 않고 암호화(해시)해서 Apps Script 설정에만 보관해요. 데이터 파일에는 PIN이 없어요.
- **잠금:** PIN을 10번 틀리면 10분 동안 로그인이 막혀요.
- **공개 범위:** GitHub Pages는 공개 저장소라서 프로그램 코드와 `config.js`의 서버 주소는 누구나 볼 수 있어요. 직원 이름과 근무표를 아무나 보지 못하게 하려면 **열람 PIN을 꼭 정하세요**. 근무표에는 환자 정보를 넣지 마세요.
- **동시 수정:** 같은 팀·같은 달을 두 사람이 동시에 고치면, 나중에 저장한 사람에게 "다른 사람이 먼저 저장했어요" 안내가 떠요. **최신 내용 불러오기**를 누른 뒤 다시 고치면 돼요. 다른 팀끼리는 서로 영향이 없어요.
- **관리자 PIN을 잊었을 때:** Apps Script 편집기 위쪽에서 함수 `resetAdminPin`을 고르고 **실행**하세요. 다음 접속 때 관리자 PIN을 새로 만들 수 있어요.

## 혼자 쓰기 모드

`config.js`의 주소를 비워 두면 서버 없이 이 브라우저에만 저장되는 혼자 쓰기 모드로 열려요. 위쪽 **미리보기**에서 팀장·직원 화면을 확인해 볼 수 있어요.
